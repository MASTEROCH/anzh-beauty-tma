# ANZH Beauty — фронтенд для правок дизайна

Срез ветки `apphub`, коммит `4622790` (15.10.2026). Это та сборка, что сейчас живёт на https://apphub-anzh.vercel.app.

## Что внутри
- `src/` — экраны, компоненты, стили (React 19 + Vite + TypeScript);
- `public/` — фото работ и мастеров, иконки, правовые тексты;
- `index.html`, `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`.

Бэкенда здесь нет — только визуальная часть.

## Как посмотреть у себя
1. Node.js 22 или новее.
2. В папке архива: `npm ci`, затем `npm run dev`, открыть адрес, который покажет консоль.

Без бэкенда экраны с данными (каталог, запись, профиль) будут пустыми или покажут ошибку загрузки — это нормально, вёрстка и стили видны.

## Как вернуть правки
Пришли изменённые файлы (или папки `src/` и `public/` целиком) архивом CEO — кабинет anzh внесёт их в репозиторий, проверит сборку и покажет результат.

Всё визуальное меняй свободно. Сетевую часть (`src/lib/session.ts` и вызовы `/api/v1`) лучше не трогать: это стык с бэкендом.
